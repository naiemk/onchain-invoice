# AGENTS.md

## Cursor Cloud specific instructions

This repo is the `onchain-invoice` payment-infrastructure library (Solidity contracts + TypeScript SDK + optional web server/client + sweep node) **and** the Trustless Commerce product (API under `commerce/`, UI under `ui/`, Docker under `deploy/`). Contract tests spin up Hardhat's in-process EVM network. The legacy `InvoiceWebServer` and the commerce API both use embedded SQLite (`better-sqlite3`) plus Node's built-in `http`.

Standard commands live in `package.json` `scripts` (`compile`, `build`, `test`, `test:contracts`, `commerce:server`, `commerce:sweeper`, `ui`, `docker:test`, `system-test`, `sweep-node`) and the README `## Development` section. Prefer those instead of ad-hoc invocations.

Non-obvious notes:
- Node 22 and dependencies are already installed by the startup update script (`npm install`). `better-sqlite3` is a native module; if it ever fails to load, run `npm rebuild better-sqlite3`.
- `npm test` runs both the Solidity/Tron contract tests and the `InvoiceWebServer` tests (all Hardhat/Mocha `.ts` files under `test/`). The web-server tests bind an ephemeral port and use in-memory/temp SQLite, so no service needs to be running first.
- Run one-off scripts (e.g. `scripts/deploy.ts`) with `npx hardhat run <path>`; they call `network.create()` to get an in-process EVM network, so no external RPC/node is required.
- There is no lint or formatter npm script. Prettier + the Hardhat Solidity extension are only configured as recommended VS Code extensions.
- `npm run sweep-node` (the generic `SweepNode` worker) is the only piece needing real config for the *library* path: a JSON config (see `node/example.config.json`) with live EVM/Tron RPC endpoints, keys, and a running web server. It is NOT exercised by the test suite and is optional for local development.
- FastSwap product code lives in a separate sibling repo (`naiemk/fastswap`), not here. Do not add FastSwap app code to this repo.
- **Trustless Commerce** lives entirely in this repo: API/sweeper under [`commerce/`](commerce/) (`npm run commerce:server` / `commerce:sweeper`), UI under [`ui/`](ui/) (`npm run ui`), Docker under [`deploy/`](deploy/) (`npm run docker:test`). **Infra packager:** sibling/npm [`vibed-infra`](https://github.com/naiemk/vibed-infra) (`vibed-infra` dep, `file:../vibed-infra` locally). Product config: [`deploy/packageconfig.yaml`](deploy/packageconfig.yaml), templates: [`deploy/templates/`](deploy/templates/). Operator one-liner install: [`deploy/install/`](deploy/install/) (`install-api.sh` / `install-nodes.sh`) or [`deploy/install.sh`](deploy/install.sh) (interactive). Local wallet-signed CREATE2 deploy console (no keys in config): [`deploy/operator/`](deploy/operator/) (`npm run deploy:console`). Dual-domain VPS stack (testnet + mainnet): [`deploy/docker-compose.domains.yml`](deploy/docker-compose.domains.yml). Product system tests against published GHCR images: [`system-tests/`](system-tests/) (`npm run system-test`, includes wget installer e2e; `npm run system-test:install` and `npm run system-test:infra-deploy`). Routes: `/` landing, `/create` invoice builder, `/pay` checkout, `/merchant` invoice list (admin is key-gated at `/admin`, not in nav). Testnet chains: Ethereum Sepolia (USDC, CREATE2), TRON Nile (USDT, EOA), Solana Devnet (USDC, PDA settle). **Mainnet rails (UI):** TRON (`tron` USDT), Base (`8453` USDC), BNB (`56` USDC+USDT) — ETH/Arbitrum disabled. API uses per-`chainId` EVM config (`EVM_8453_*` / `EVM_56_*`); create returns 503 until that chain’s sweeper/forwarder is set. Launch checklist: [`deploy/operator/README.md`](deploy/operator/README.md#mainnet-launch-checklist-tron--base--bnb).
- **Commerce env loading:** `npm run commerce:server` runs from the repo root, and `dotenv/config` loads **`.env` from cwd** (repo root), not `commerce/.env`. Copy `commerce/.env.example` → `.env` at the root for local API runs. For offline CREATE2 `invoiceAddress` derivation without a live RPC, set both `SWEEPER_ADDRESS` and `FORWARDER_IMPLEMENTATION` (see `system-tests/.env.example` throwaway pair). Multi-chain mainnet: also set `EVM_8453_SWEEPER_ADDRESS` / `EVM_8453_FORWARDER_IMPLEMENTATION` and `EVM_56_*`. Build first with `npm run commerce:build` (or `npm run build`) before `commerce:server`.
- **AI agents creating invoices:** use Cursor skill [`.cursor/skills/trustless-commerce-invoice/SKILL.md`](.cursor/skills/trustless-commerce-invoice/SKILL.md) (`POST /api/invoices` one-shot). Product docs: `docs/` (MkDocs → GitHub Pages).
- It uses the **Commerce** contracts (`contracts/commerce/`) and `CommerceInvoiceSdk` for EVM; Nile/Tron mainnet use `deriveTronInvoiceAddress` + sponsor sweep (no commerce Tron contracts yet). Solana (devnet) uses a PDA settle program under [`solana/`](solana/) + `CommerceSolanaSdk` (`npm run solana:test`, `solana:deploy:devnet`, `solana:smoke:devnet`). Operator sweepers: wget [`deploy/install/install-nodes.sh`](deploy/install/install-nodes.sh) → triple compose (Sepolia + Nile + Solana Devnet).
